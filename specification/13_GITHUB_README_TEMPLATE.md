# AI Project Architect

AI-assisted software project planning platform that transforms a natural-language idea into requirements, architecture, database design, tasks, team assignments, dependencies, and technical documentation.

## Features
- Requirements analysis
- Architecture planning
- Database planning
- Task decomposition
- Team-role assignment
- Dependency validation
- Documentation
- Mock AI mode
- Export

## Stack
Next.js + TypeScript, FastAPI + Python, PostgreSQL, SQLAlchemy, Pydantic, Docker Compose.
