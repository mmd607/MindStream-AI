# Frontend Specification

## Stack
Next.js, TypeScript, React, Tailwind CSS.

## Pages
- Landing
- Create Project
- Project Dashboard
- Requirements
- Architecture
- Database
- Tasks
- Team
- Documentation
- Export

## Dashboard
Show generation status and metrics such as requirement count, component count, database entity count, and task count.

## Tasks
Support filtering by status, priority, role, and effort. Show dependencies and acceptance criteria.

## UX
Use reusable components, typed API clients, validation, loading/error/empty states, accessible controls, and responsive layouts.

## Diagrams
Render architecture and database relationships with Mermaid or a diagram library. Fail gracefully if rendering is unavailable.
