# Prompt Update Guide

Update the relevant specification before implementing a new feature.

For authentication, update PRD, architecture, backend, security, database, API, and roadmap.

For GitHub integration, add a repository adapter/service, repository model, import workflow, security restrictions, and UI.

For a future multi-agent architecture, preserve current planner interfaces and add an agent registry, shared project context, execution state, permissions, queue, and observability.

Keep future changes incremental and versioned.
